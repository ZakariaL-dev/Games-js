## 🕹️ Project Overview
**Games-JS** is a playground for web-based gaming. This repository features a variety of interactive games built using **HTML5, CSS3, and Vanilla JavaScript**. It’s designed to demonstrate DOM manipulation, game logic, and event handling while providing a fun experience for players.

## ✨ Key Features
* **👾 Retro Mechanics:** Classic gameplay loops reimagined for the web.
* **⚡ Zero Dependencies:** Built with pure JavaScript—no heavy frameworks required.
* **🎨 Smooth Visuals:** Clean CSS animations and responsive canvas rendering.
* **🔊 Interactive Feedback:** Instant score updates and game-state transitions.
* **📱 Play Anywhere:** Works directly in any modern web browser.

## 🛠️ Installation & Setup
Getting these games running on your machine is simple:

1.  **Clone the Repository**
    ```bash
    git clone [https://github.com/ZakariaL-dev/Games-js.git](https://github.com/ZakariaL-dev/Games-js.git)
    ```
2.  **Navigate to the Folder**
    ```bash
    cd Games-js
    ```
3.  **Run a Game**
    Open any game's folder and launch the `index.html` file in your browser:
    ```bash
    # Example
    open index.html 
    ```
